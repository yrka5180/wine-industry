# wine-industry

集成电路、智能传感与数据分析在传统酒水生产中的应用研究，重点关注黄酒。

**调研日期：2026-09-30。** 本轮是公开资料调研，不是工厂实测、采购选型或工程设计验收。仓库只收录公开信息、研究分析和明确标注的演示假设，不包含酒厂配方、内部生产记录或个人信息。

## 先看结论

建议先验证两类项目：**批次过程监测与损耗定位**、**CIP 清洗及水汽能耗计量**。优先复用现有 PLC、仪表和检验记录，再补充传感器；近红外与电子鼻作为独立验证课题，不宜一开始就承担自动调配、成品放行或食品安全判断。

这个判断有三类依据：黄酒企业的成本构成、黄酒相关的原始实验研究，以及其他食品饮料行业的已披露应用。它们的适用范围不同，不能把论文指标、厂商案例和本项目收益混在一起。

## 证据怎么读

- **直接证据**：黄酒企业自身披露、黄酒实验研究；仍需区分经营数据、实验性能和实际改造收益。
- **迁移参考**：葡萄发酵、啤酒、乳品等场景；不直接套用其精度、成本或节省比例。
- **器件与产品能力**：原厂资料能够证明功能和规格，不能单独证明整套系统的效果。
- **本报告建议／演示假设**：方案设计、试点门槛和收益情景，不作为已证实事实。

核心材料包括会稽山 2025 年年报及 2026 年半年报、黄酒 FT-NIR 与电子鼻研究、可阅读全文的光谱验证研究，以及 TI、ADI、NXP、ifm、Precision Fermentation、MVTec 的原始资料。具体数字请连同[证据索引](docs/evidence-register.md)中的限制条件一起阅读。

## 运行演示测算

```bash
python3 scripts/roi_model.py
# 使用自己的参数：
python3 scripts/roi_model.py --config path/to/assumptions.json
```

脚本输出年度毛节省、年度净现金收益、简单回收期，以及达到目标回收期所需的材料节省率。负净收益不会显示成可回收项目。该模型不含税、资金时间价值、爬坡期、融资和设备更新，不应替代正式投资评估。

## 当前未解决的问题

尚未取得目标工厂的损耗分布、实际水汽单耗、停机损失、仪表清单及安装报价；也没有核实到可直接套用于黄酒厂的长期多批次收益数据。因此，本轮可以支持“选什么方向、验证什么”，不能承诺“投资多少、必然省多少”。
